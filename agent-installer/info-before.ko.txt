SIMA Asset Monitoring Agent
============================

이 프로그램은 PT Adhi Kartiko Pratama Tbk(AKP)의 공식 소프트웨어로, 회사 IT 자산
(노트북/PC)의 상태를 모니터링하기 위한 것입니다. AKP IT팀이 설치, 관리 및
감사합니다.

이 설치 프로그램은 두 가지 프로그램을 설치합니다. SIMA Asset Agent는 자동으로
설치되며, Net Monitor for Employees Pro는 선택 사항으로 마지막 페이지에서 직접
체크한 경우에만 실행됩니다(아래 2부 참조).

====================================================
1부 — SIMA Asset Agent (자동 설치)
====================================================

이 에이전트는 무엇을 하나요?
------------------------------
에이전트는 5분마다 회사의 SIMA 서버(자산 정보 관리 시스템)로 짧은 보고서를
보낸 뒤 다음 주기까지 종료됩니다. 흔적 없이 몰래 실행되는 것은 없습니다. 모든
활동은 이 컴퓨터에 접근할 수 있는 누구나 언제든 열어볼 수 있는 로그 파일
(agent.log)에 기록되며, 에이전트는 가명이 아닌 "SIMA Asset Agent"라는 분명한
이름으로 Windows 작업 스케줄러에 등록됩니다.

SIMA 서버로 전송되는 데이터:
------------------------------
  - 컴퓨터 이름(호스트 이름)과 로컬 IP 주소
  - Windows 버전, 빌드 및 아키텍처
  - 도메인/작업 그룹, 컴퓨터를 마지막으로 다시 시작한 시각
  - 장치의 제조사, 모델, 일련번호(BIOS에서 읽음)
  - 프로세서(CPU): 모델, 코어/스레드 수, 클럭, 캐시, 순간 부하
  - RAM: 용량, 남은 양, 슬롯 수, 각 모듈(종류, 속도, 제조사)
  - 모든 드라이브(용량 및 여유 공간)와 물리 디스크 상태
  - 네트워크: 연결 유형, Wi-Fi 이름(SSID), MAC 주소, IP 및 게이트웨이
  - 배터리: 잔량, 전원 상태, 배터리 상태
  - BitLocker 상태(디스크 암호화 여부)
  - Windows Defender 상태 및 바이러스 정의 업데이트 날짜
  - 마지막으로 설치된 Windows 업데이트와 설치 대기 중인 업데이트
  - 설치된 소프트웨어 목록(이름, 버전, 게시자), 하루 한 번 전송
  - RAM 및 디스크 읽기/쓰기 속도 테스트 결과, 하루 한 번(즉시 삭제되는
    256MB 임시 파일 사용)

SIMA 서버는 에이전트의 보고서를 비교하여 장치 사양의 변경 이력(예: RAM 증설,
소프트웨어 설치 또는 삭제)도 기록합니다.

IT팀의 요청(고정 목록)
------------------------------
IT팀은 에이전트에게 고정된 목록 안의 몇 가지 작업만 요청할 수 있습니다. 전체
보고서 지금 보내기, 진단 정보 또는 에이전트 로그 수집, 화면에 짧은 메시지
표시입니다. 에이전트는 다른 명령, 스크립트 또는 프로그램을 실행하도록 지시받을
수 없으며, 사용자의 파일을 변경하거나 삭제할 수 없습니다. 모든 요청은 이
컴퓨터의 agent.log와 SIMA의 기록(요청자, 시각, 결과)에 남습니다.

도우미 프로그램 "SIMA Agent Helper"(트레이 아이콘)
------------------------------
이 작은 프로그램은 사용자 본인의 계정(관리자 권한 없음)에서 실행되며 두 가지만
수행합니다. IT의 공지를 카드 형태로 화면에 표시하고, IT가 대화를 시작하면 채팅
창을 엽니다.
  - 채팅은 항상 IT가 시작하고 종료합니다. 사용자는 답장하고 창을 최소화할 수
    있지만 대화를 종료할 수는 없습니다. 대화는 30분 동안 활동이 없으면
    자동으로 종료됩니다.
  - 채팅 내용은 보낸 사람의 이름과 시각과 함께 SIMA에 저장됩니다.
  - 이 프로그램은 사용자의 파일, 화면, 클립보드 또는 키 입력을 읽지 않습니다
    (채팅 창으로 보낸 텍스트만 해당).
  - 활동은 %LOCALAPPDATA%\SIMA\helper.log에 기록됩니다.

SIMA Asset Agent가 절대 전송하지 않는 데이터:
------------------------------
  - 키보드 입력 기록(키로깅) 없음
  - 스크린샷 또는 화면 녹화 없음
  - 인터넷 사용 기록 또는 브라우저 내용 없음
  - 파일 또는 개인 문서의 내용 없음
  - 정확한 위치(GPS) 없음, 사무실 네트워크 IP만 해당
  - 카메라, 마이크 또는 클립보드 접근 없음

====================================================
2부 — Net Monitor for Employees Pro (선택 사항, 자동 설치 아님)
====================================================

이것은 EduIQ.com의 별도 프로그램이며 AKP가 만든 것이 아닙니다. SIMA Asset
Agent와는 크게 다릅니다. 설치하기로 선택하면(마지막 설치 페이지의 체크박스)
다음이 가능합니다.

  - 관리자 컴퓨터에서 이 컴퓨터의 화면을 실시간으로 보기
  - 스크린샷 촬영 및 화면 녹화
  - 키보드 입력 기록(키로깅)
  - 마우스와 키보드를 원격으로 제어
  - 특정 응용 프로그램 또는 웹사이트 차단
  - USB 포트 잠금
  - 이 컴퓨터를 원격으로 종료 또는 다시 시작

이는 SIMA Asset Agent보다 훨씬 광범위한 모니터링 기능입니다. SIMA Asset Agent와
함께 자동으로 설치되지 않습니다. 마지막 페이지에서 "Net Monitor for Employees
Pro도 설치"를 의식적으로 체크한 경우에만 설치 프로그램이 실행되며, 그 후 해당
프로그램 자체의 설치 마법사가 별도로 표시됩니다(숨겨지지 않음).

직원의 컴퓨터에 Net Monitor for Employees Pro를 설치하기 전에 회사 정책에 따라
설치가 승인되었는지, 그리고 직원에게 알렸는지 확인하십시오. 키 입력 및 화면
모니터링은 많은 지역에서 노동법/개인정보 보호법의 규제를 받습니다.

====================================================

이 설치는 반드시 관리자 권한으로 실행해야 합니다. SIMA Asset Agent는 사용자별이
아니라 시스템 수준에서 실행되는 작업 스케줄러로 등록되어, 아무도 로그인하지
않아도 계속 보고하기 때문입니다.
